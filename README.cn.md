# ugrep

[English](./README.md)

🔍 ugrep 7.8 文件模式搜索器 — 更友好的、更快、更强大的 grep 替代工具。包含 TUI 界面、类似 Google 的 AND/OR/NOT 布尔搜索、模糊搜索、十六进制转储、（嵌套）归档（zip、7z、tar、pax、cpio）与压缩文件（gz、Z、bz2、lzma、xz、lz4、zstd、brotli）、PDF、文档等。
